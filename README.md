Formulário básico iniciante

Objetivo principal
Desenvolver uma aplicação web que simule um formulário de cadastro

Objetivos secundários
- Implementar chamadas HTTP para comunicar com o back-end
- Implementar JWT
- Construir um Front-end com HTML e CSS puro
- Utilizar o swagger para documentar as requisições HTTP
- Construir o Banco de Dados com Postgres
- Povoar o banco de dados com dois usuário: um Admin e outro Cliente

Permissões do Admin
- Buscar usuários cadastrados
- Atualizar dados de um cliente
- Excluir cadastro

Ferramentas utilizadas:
- Aplicação desenvolvida em Espress.js
- Front: HTML e CSS puro
- Back: JavaScript
- Banco de Dados: Postgres
